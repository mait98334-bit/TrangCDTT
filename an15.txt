À, lý do file .env bị mất khi bạn đẩy lên Git rồi lấy về là do trong dự án có một file đặc biệt tên là 

.gitignore
.

Giải thích nguyên nhân:
Bảo mật: File .env thường chứa các thông tin nhạy cảm của hệ thống như tài khoản, mật khẩu database, hoặc các khóa bảo mật thanh toán (như VNPAY hash secret). Nếu đẩy các thông tin này lên GitHub (đặc biệt là repo công khai), kẻ xấu có thể quét và lợi dụng.
Quy chuẩn lập trình: Vì lý do bảo mật ở trên, các lập trình viên đã thêm dòng backend/.env vào file .gitignore (file khai báo những gì Git không được phép theo dõi và tải lên).
Do đó, khi bạn chạy git push, file .env chưa từng được đẩy lên GitHub, dẫn đến việc khi bạn tải code về ở một nơi khác (hoặc tạo thư mục mới), file này sẽ không có sẵn và bạn phải tự tạo lại thủ công.
Giải pháp tối ưu:
Để sau này bạn hoặc người khác tải dự án về không bị bỡ ngỡ và biết cần điền những thông số gì, tôi đã tạo giúp bạn một file mẫu tên là 

.env.example
.

File này không chứa mật khẩu thật và được phép đẩy lên Git. Sau này khi tải code về máy mới, bạn chỉ cần:

Copy (nhân bản) file .env.example thành .env.
Điền thông tin kết nối database của máy đó vào là xong!
